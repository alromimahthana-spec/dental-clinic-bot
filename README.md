# 🦷 بوت حجز عيادة أسنان
### ثناء | thanaa.codes

بوت يحجز مواعيد عيادة الأسنان، يخلي المريض يختار الخدمة والدكتور واليوم والوقت، ويأكد له الحجز تلقائياً.

## ✨ وش يسوي؟
- يعرض 7 خدمات: كشف، تنظيف، حشوة، خلع، تقويم، تبييض، تركيب
- يخلي المريض يختار الدكتور: عام، تجميل، تقويم، أطفال
- يخلي المريض يختار اليوم: من السبت الى الخميس
- يخلي المريض يختار الوقت: من 9 صباحا الى 8 مساء
- يستلم اسم المريض ورقمه وعمره
- يعرض تأكيد الحجز كامل مع السعر

## 🚀 كيف تشغليه؟
python dental-clinic-bot.py

## 💰 السعر
2000 ريال سعودي - نسخة كاملة لعيادات الأسنان

## 📦 مثال على الحجز
الخدمة: تنظيف الأسنان
الدكتور: د. سارة - تجميل
اليوم: الأحد
الوقت: 4 عصرا
السعر: 150 ريال
